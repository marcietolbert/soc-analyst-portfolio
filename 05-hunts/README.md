# Threat Hunting Exercises

This section documents small, hypothesis-driven threat hunting exercises designed to identify potentially suspicious activity within security telemetry.

Each hunt will focus on a defined hypothesis, relevant data sources, search methodology, supporting evidence, and documented findings.

## Planned Artifacts

- Tiny Hunt Template
- Hunt 001 — Failed Authentications Followed by Success
- Hunt 002 — Suspicious Process Execution

Exercises will distinguish between confirmed findings, inconclusive results, and activity that was not observed within the available data.
