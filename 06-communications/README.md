# SOC Communications and Reporting

This section demonstrates how security investigation findings can be communicated clearly, accurately, and appropriately to different audiences.

The focus is on concise reporting, evidence-based updates, effective analyst handoffs, and communicating security risks without overstating conclusions.

## Planned Artifacts

- Security Update Templates Library
- Manager Update Example
- Executive Update Example
- Analyst Handoff Template

Examples will distinguish confirmed findings from preliminary assessments, identify outstanding questions, and communicate recommended next steps.
