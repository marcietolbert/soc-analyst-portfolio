# SOC Analyst Portfolio

**Security Monitoring | Alert Triage | Incident Investigation**

## About This Portfolio

This portfolio documents my practical development toward a Tier 1 Security Operations Center (SOC) Analyst role.

Through hands-on labs, simulated SOC environments, and security investigation exercises, I am developing repeatable workflows for assessing alerts, validating suspicious activity, correlating evidence, documenting findings, and communicating security decisions.

My focus is on demonstrating how I approach security problems, evaluate evidence, and make defensible decisions.

## Portfolio Sections

| Section | Description |
|---|---|
| [Triage](01-triage/) | Alert assessment, validation, prioritization, and escalation workflows. |
| [Cases](02-cases/) | Structured case reports and investigation outcomes. |
| [Investigations](03-investigations/) | Evidence collection, log correlation, and investigation methodology. |
| [Detection](04-detection/) | Detection feedback, false-positive analysis, and improvement recommendations. |
| [Hunts](05-hunts/) | Small, hypothesis-driven investigations using security telemetry. |

| [Lab](08-lab/) | Technical exercises, queries, and documented training environments. |
